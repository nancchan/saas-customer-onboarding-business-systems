# Power BI Reporting & Dashboard

## Overview

This folder contains the Power BI reporting work created from the cleaned customer dataset used in the SaaS customer onboarding project.

The purpose of the Power BI work is to transform validated customer data into business-focused reports and visualizations that support customer analysis and onboarding review.

## Data Source

Power BI uses the cleaned customer dataset prepared during the data-quality process.

The cleaned dataset contains **16 unique customer records** with the following fields:

- First Name
- Last Name
- Email
- Phone
- Account Name

The cleaned dataset is maintained in the Excel folder as:

`cleaned_customer.xlsx`

This prevents multiple versions of the customer dataset from being treated as separate sources.

## Reporting Objectives

The Power BI report is used to analyze:

- Total customer records
- Customer distribution by Account
- Customer information by Account
- Customer data completeness
- Customer onboarding information

## Dashboard

The dashboard provides a visual summary of the customer dataset.

Key reporting views include:

- Total customer count
- Customer distribution by Account
- Account-level customer analysis

## Business Analysis Connection

Power BI demonstrates how validated customer data can be transformed into business information for analysis and decision-making.

The reporting workflow connects:

**Customer Data → Data Quality → CRM → Reporting → Business Analysis**

## Validation

Power BI results should be compared against the validated customer dataset and Salesforce reporting results to confirm that:

- Customer counts are consistent.
- Account information is represented correctly.
- No unexpected records are included.
- Report results reflect the underlying customer data.

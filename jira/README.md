# Jira — Implementation Workflow

## Overview

Jira was used to organize and track the simulated SaaS customer onboarding and implementation work.

The project workflow followed:

**To Do → In Review → In Progress → Done**

Implementation activities were organized into individual work items and progressed through the workflow to simulate how implementation work can be planned, tracked, reviewed, and completed.

## Implementation Activities

The Jira project was used to track activities related to:

- Business requirements
- Customer data preparation
- Data quality review
- Salesforce CRM configuration
- Data mapping
- CRM validation
- Reporting
- UAT and testing
- Troubleshooting
- Project documentation

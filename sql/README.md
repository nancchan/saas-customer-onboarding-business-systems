# SQL Investigation

## Overview

This section contains SQL queries used to investigate customer data during a simulated SaaS customer onboarding process.

The objective was to practice reviewing customer records, identifying data quality issues, and supporting troubleshooting activities before customer information is imported into Salesforce.

---

# Investigation Scenarios

The SQL queries demonstrate how customer data can be reviewed to identify issues that may affect onboarding.

Examples include:

- Looking up customer records
- Identifying missing information
- Reviewing invalid email addresses
- Detecting incomplete customer data

---

# Purpose

SQL is commonly used by implementation, operations, and support teams to investigate customer information during onboarding and troubleshooting.

These examples demonstrate basic data investigation techniques using realistic customer onboarding scenarios.
